El trabajo consiste en hacer portafolio personal con informacion mia y de los proyectos que hice.

Este esta dividido en 4 secciones:
-inicio: aparece mi nombre y es lo primera que se ve al entrar a la pagina.
-sobre mi: una seccion con datos mios, los cuales son mi nombre, mi edad, el año que estoy cursando y la escuela a la que voy.
-proyectos: seccion en la que estan los enlaces para visitar los repos de los trabajos que hice.
-contactos: link a mis redes sociales.

los archivos se dividen en:
-index.html: en donde esta la estructura y contenido del sitio.
-styles.css: en donde esta todo el diseño de la pagina.

Para hacer este trabajo use html para la estructura, css para el diseño, bootstrap para conseguir iconos y google fonts para obtener la fuente.
